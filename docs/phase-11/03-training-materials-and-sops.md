# Phase 11: Training Materials and SOPs

## Audience
- Ministry administrators
- Reviewers
- Field contributors
- Support and operations staff

## Required Training Packs
1. Admin pack:
   - user/project setup
   - assignment approval flow
   - review queue management
   - export requests and download workflow
2. Field contributor pack:
   - login and project access
   - add feature flow and photo capture
   - offline behavior and sync recovery
   - submission workflow
3. Support/ops pack:
   - incident triage
   - log/request-id tracing
   - backup/restore escalation path
   - rollback protocol

## SOP Baseline
- SOP-01: User onboarding/deactivation.
- SOP-02: Project creation and assignment lifecycle.
- SOP-03: Field data collection quality checks.
- SOP-04: Review and rejection-note standards.
- SOP-05: Export processing and fulfillment.
- SOP-06: Incident response and escalation.
- SOP-07: Backup verification and restore execution.
- SOP-08: Monthly release preparation and sign-off.

## Evidence of Completion
- Attendance records for each role group.
- Practical exercises completed by pilot users.
- Signed SOP acceptance by ministry ops representatives.
