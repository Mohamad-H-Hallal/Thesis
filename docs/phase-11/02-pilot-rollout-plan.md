# Phase 11: Pilot Rollout Plan

## Objective
Run a controlled pilot with ministry users before national production launch.

## Pilot Scope
- Regions: start with 1-2 representative governorates.
- Users: limited admin/reviewer group + selected contributors.
- Features in scope:
  - project assignment and collection
  - draft/submit/review workflow
  - exports and basic reporting
  - offline-first sync behavior

## Pilot Timeline (Template)
1. Week 1: environment freeze, accounts provisioning, device preparation.
2. Week 2: training + dry run with sample projects.
3. Week 3-4: live pilot operations with daily support window.
4. Week 5: pilot evaluation, defect triage, go/no-go decision.

## Pilot Go/No-Go Metrics
- Uptime target met for pilot window.
- Critical severity defects: `0`.
- Data integrity incidents: `0`.
- Sync success rate above agreed target.
- Median BBOX response and export completion within operational baseline.
- User acceptance sign-off from ministry stakeholders.

## Pilot Operations Cadence
- Daily standup: operations + product + technical lead.
- Daily KPI report:
  - submitted features
  - review turnaround
  - failed sync jobs
  - failed exports
- Weekly stakeholder checkpoint with risk review.
