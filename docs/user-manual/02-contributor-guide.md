# Contributor Guide

## Daily Start
1. Login.
2. Open `Home/Projects`.
3. Use search to find assigned project.

## Capture a New Feature
1. Open project details.
2. Tap `New Feature`.
3. Follow stepper:
   - Step 1: Geometry placeholder (current build).
   - Step 2: Attributes form.
   - Step 3: Photos add/remove.
   - Step 4: Review and save draft.
4. Save as draft.

## Manage Drafts
1. Open `Drafts` tab.
2. Review status chips (`draft`, `pending_review`, `rejected`).
3. Tap draft to edit and resubmit.

## Submit for Review
1. From draft details, submit feature.
2. Status changes to `pending_review`.
3. Track updates in `Notifications`.

## Use Map Screen
1. Open `Map` tab.
2. Check GPS status and sync status chip.
3. Use `Add Feature` floating action button.

## Best Practices
- Capture complete attributes before submit.
- Attach photos when required by project rules.
- Resolve rejected notes before resubmitting.
