# Project Admin Guide

Project Admin refers to users with project-level admin assignment role.

## Project-Level Responsibilities
1. Review assignment roster for your project.
2. Validate submissions and data quality.
3. Coordinate contributors and submission timelines.

## Review Queue
1. Open `Review Queue` (if your role has reviewer privileges in app shell).
2. Filter pending items.
3. Approve valid submissions.
4. Reject invalid ones and add review notes.

## Assignment Oversight
- Confirm users are assigned to correct project.
- Escalate assignment creation/removal to system admin if endpoint policy is admin-only.

## Data Quality Checklist
- Geometry is valid for project rules.
- Attributes are complete and consistent.
- Photo evidence meets policy.
- Rejected entries include actionable notes.

## Export Coordination
- Request exports for approved datasets.
- Verify export status and download when ready.
