# Lebanese GIS Fruit Trees Collector - Revised Plan (No AI)

## Phase 0 - Environment, Repo Scaffold, and CI Baseline
Goal: Clean monorepo that boots locally and is ready for secure development.

## Phase 1 - Scope + Governance Baseline (Soft Freeze)
Goal: Define product scope and permissions without freezing survey forever.

## Phase 2 - Database + Core API Contract (v0)
Goal: Build DB and API foundations (auth, projects, categories, assignments, features CRUD).

## Phase 3 - Geospatial API + Performance Baseline
Goal: Validate PostGIS behavior and map query performance early.

## Phase 4 - Mobile App Foundation
Goal: Build Flutter architecture baseline with auth/session/env foundations.

## Phase 5 - Offline-First Core + Sync
Goal: Implement robust local-first data model and sync pipeline.

## Phase 6 - Field Collection UX
Goal: Deliver field collection workflows; freeze data dictionary + API after pilot.

## Phase 7 - Review and Workflow
Goal: Complete draft/submit/review approval lifecycle and notifications.

## Phase 8 - Exports + Reporting
Goal: Add async export jobs, status tracking, and baseline dashboards.

## Phase 9 - Security, Reliability, Observability
Goal: Operational hardening: TLS, audit logs, backup/restore drills, monitoring.

## Phase 10 - Quality Engineering
Goal: Mature test pyramid, performance tests, and release quality gates.

## Phase 11 - Deployment, Rollout, and Operations
Goal: Stage, pilot rollout, training/SOPs, production go-live, and release cadence.
